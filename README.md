# Learning-Python

Learning Python, LOTS Of Mistakes. 

This repository tracks my progression from absolute beginner to writing functional network automation scripts. The code here documents my trial-and-error process of learning core programming logic, debugging syntax, and leveraging the Python REPL for rapid testing.

**Current Learning Objectives**
* Mastering basic data types, type conversions, and variables.
* Controlling script execution using If/Else logic and For/While loops.
* Manipulating complex data structures like Lists and Dictionaries.
* Writing user-defined functions to make code reusable.

**Project Roadmap**
* **Stage 1:** Foundations of Programming (Core Syntax & Logic)
* **Stage 2:** Python for IT Automation (Interacting with network devices)
* **Stage 3:** Cisco DevNet Fundamentals (APIs, JSON parsing, CI/CD)

**Environment Setup**
* **Language:** Python
* **Editor:** VS Code
* **Testing:** Python REPL / Interactive Terminal
